# Ôn tập BJT

Trang ôn tập tiếng Nhật thương mại (BJT), mỗi lượt tối đa 20 câu trắc nghiệm, có giọng đọc Tokyo (ja-JP-NanamiNeural).

Mở trang: https://bsj-hoa-le.github.io/bjt/

- **Từ vựng** (`tu-vung.html`): 45 bài, khoảng 2.200 từ. Cách đọc, ý nghĩa, chọn từ, điền vào câu.
- **Ngữ pháp** (`ngu-phap.html`): 117 mẫu J3~J2, điền mẫu vào hội thoại.
- **Kính ngữ** (`kinh-ngu.html`): tôn kính ngữ, khiêm nhường ngữ, từ ngữ công sở, lỗi kính ngữ thường gặp.

Tiến độ lưu trên trình duyệt của từng người (localStorage).
